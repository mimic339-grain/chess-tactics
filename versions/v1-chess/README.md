# チェス（改造ベース）

ブラウザで動くチェス。ここから少しずつルールを変えて新しいゲームを作るための土台。

## 遊び方

`index.html` をブラウザで開くだけ（ダブルクリックでOK）。

- 駒をクリック → 動けるマスが表示 → 行き先をクリック
- 一手戻す / 盤を反転 / CPU 対戦（CPU は黒）

## ファイル構成

| ファイル | 中身 | 改造のしやすさ |
|---|---|---|
| `js/pieces.js` | 駒の動き・初期配置・昇格先 | ★ まずここ |
| `js/engine.js` | 合法手生成、チェック/詰み/引き分け判定、棋譜 | 特殊ルールを足すとき |
| `js/ai.js` | CPU（駒得だけ見る3手読み） | |
| `js/ui.js` | 盤面の描画とクリック操作 | |
| `test.html` | ルールが正しいかのテスト（perft） | エンジンを変えたら開いて確認 |

## 改造の例（`js/pieces.js`）

```js
// ナイトに「キングの動き」を追加する
N: { ..., moves: [{ type: 'leap', dirs: KNIGHT }, { type: 'leap', dirs: ALL8 }] },

// 前と斜め前にだけ1マス進める新しい駒（白から見て dy=-1 が前）
G: { name: 'ガード', symbol: 'G', value: 2, moves: [{ type: 'leap', dirs: [[0,-1],[1,-1],[-1,-1]] }] },
```

新しい駒を足したら `INITIAL_LAYOUT` に文字（白は大文字、黒は小文字）を置けば盤に出る。
`INITIAL_LAYOUT` の行数・列数を変えると盤のサイズも変わる。
