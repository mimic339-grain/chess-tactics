# チェス・タクティクス

チェスをベースにしたマス目タクティクスゲーム（FFタクティクスやデビサバのような遊び方）。

## 遊び方

`index.html` をブラウザで開くだけ。

### デッキ構築（試合前）

- 最初にデッキ構築画面が出る。キャラを選んで、自分の陣営（横10×縦3・光っているマス）に置く
- 置いたキャラを押すと持ち上げて動かせる。右クリックで外す。「おまかせ配置」でいつもの並び
- キング枠はちょうど1体。キャラごとに入れられる数の上限がある（`units.js` の `deckMax`）
- 白 →（CPU 対戦でなければ）黒 の順に配置して試合開始。前回のデッキはブラウザに保存される

- 1ターンに **3キャラ** まで動かせる。各キャラは **移動してからスキルも使える**（移動後の攻撃はダメージ ×0.7、四捨五入・最低1）
- 移動したあと攻撃しないなら「待機」で行動を終える。`units.js` の `RULES.moveAndAct` / `movedAttackRate` で切り替え・調整できる
- キャラをクリック → 横に出るメニューで行動を選ぶ → 青（移動先）か赤/緑（対象）のマスをクリック
- 3キャラ動かすと自動で相手のターンになる。途中でやめるなら「ターン終了」
- 自分のターンの始めに、全キャラの HP が 1 回復する
- **相手のキングを倒したら勝ち**
- 右クリックか Esc で選択解除
- 行動メニューは上のつまみ（⠿）をドラッグして好きな場所に動かせる。ダブルクリックで元に戻る

- 移動先のマスには、そこまで行くと移動HPをいくつ使うかが表示される
- **弾**：ウィッチの魔力・アーチャーの矢。スキルを使うと減り、毎ターン少し回復。足りないとそのスキルは使えない

### レオニダス「来たりて取れ」

- **ファランクス**：好きな味方を選ぶと、その味方と左右につながって並んでいる味方をまとめて上下左右に最大2マス動かせる（レオニダス自身が入っていなくてもよい）。動いた全員は相手のターンの間、遠距離（2マス以上離れた所から）のダメージが半分になる
- **陣形移動**：好きなマスを選ぶと、そこを中心にした9マスにいる味方をまとめて最大2マス動かせる
- 一緒に動いた味方は移動HP を払うが、そのターンの行動はまだ残る（使うのはレオニダス1人分の行動）
- キング枠は今後ドラゴン系などを `royal: true` で増やせる

### 操作のコツ

- 範囲のあるスキル（黒刀・貫通・ドラゴンチャージ・エクスプロージョン・範囲魔法・ブレス・蒼炎など）は、1回押すと赤い範囲が出る。もう一度同じマスを押すか「決定」で発動
- スキルを選んだあとに対象でないマスを押すと、スキルをやめて移動に戻る。「移動」ボタンを押せばいつでも移動に切り替わる
- デッキ構築の「ランダム編成」で、枠を守ったまま編成と配置をランダムにできる
- 最初の画面の一番上でモードを選ぶ：**1人で遊ぶ**（CPU と対戦）／**2人で遊ぶ**（交代で操作）／**観戦**（CPU 同士。両方おまかせ・両方ランダム・白は自分のデッキ から選べる）。試合中の「CPU の速さ」で速さを変えられる

### セミラミスの土台（浮遊要塞）の建物

- **アルテミス砲**（3ターン）：土台の外周の端（角と真ん中以外）に建つ砲台。外向きの扇形（90度）7マスにだけ撃てる。HP12で壊される。セミラミスの「修理」でHP+4（3回）
- **エネルギー生成所**（2ターン）：土台に建つ。あるあいだ毎ターン、セミラミスの MP +2。HP8・修理できる
- **土台拡張**：土台が1マス広がる（3×3 → 5×5 → 7×7）。n 回目は 2n ターン
- **タレット**（2ターン）：毎ターン近くの敵を自動で撃つ

### 王龍ゼノ（キング枠）

- 置いた場所に **霊廟（HP30・動かない）** ができ、ゼノは霊廟の前に立つ。**霊廟を壊されたら負け**（ゼノが倒されても負けない）
- ゼノは HP2・攻撃2 から始まり、倒されると次の自分のターンに霊廟のそばで復活。n 回目の復活で最大HP・攻撃が 2+2n

### 補給路にいると回復

自分の補給路（浮遊要塞の上も）にいると、自分のターン開始時に HP・移動HP・MP・矢が回復する（移動して補給路で止まったときにも回復）

### 先攻・後攻とポイント

- 全キャラに **移動速度**（満タンの移動HPで何マス動けるか）がある。配置したキャラの合計が大きい側が先攻（同じなら白）
- **ポイント**：自分のターンが来るたびに +1。右パネルの「増援を呼ぶ」でポーン枠キャラを自分の陣地に出せる（1ターン1回・行動回数は使わない）。オーバーロードの呪力強化にも使う

### 旗と城（陣取りルーク）

- 陣取りルークが止まった場所に **旗（⚑）** が立ち、周囲9マスがその側の拠点になる
- 9マスの外周に **軽い壁**。相手の遠距離攻撃を1回防いで壊れる
- **奪取**：旗の9マスに相手のキャラだけがいる状態で相手のターンが来ると、旗ごと奪われる（壊れた壁は元に戻る）
- **築城**：旗の9マスの中にいる味方は「築城：砦」を選べる。2ターンかけて建てる。そのあいだそのキャラは動けず、反撃もできず、受けるダメージ2倍（無防備）
- **砦**：HP 10。相手の遠距離攻撃は砦が代わりに受ける。中の味方は「修理」でHP+4（3回まで）
- 旗の9マスに自分の補給路が届いていると、自分のターン開始時に修理回数 +1（最大6）
- 城の段階（2段目以降）は `units.js` の `FORT.levels` に足していく
- 勝ち方は相手のキングを倒すことだけ

### 戦闘の基本ルール

- **射線**：2マス以上離れた弓・魔法の単体攻撃は、間に誰か（味方も）がいると撃てない。一番手前の敵だけ狙える
- **反撃**：攻撃された側は、相手が自分の射程にいて弾（矢・MP）が足りていれば1回殴り返す（全員）。罠にかかったキャラは反撃できない
- **防壁**：陣取りルークが止まると、その9マスの外周に防壁ができる。相手の遠距離攻撃は1回防がれて、防壁が壊れる
- **透明**：アサシンの透過中は相手から見えず狙われない。相手の陣営に入る・アラートの範囲に入る・攻撃すると見つかる
- 2人対戦では、相手の透明キャラ・罠・アラートは手番の側の画面には出ない

- 片方のゲートに入ると、もう一方のゲートから出る（移動先に 🌀 マークが付く）。ゲートの上に立っている味方は、もう一方へ移動HP 0 で移動できる
| ナイト | 7 | 3 | 6（1回の跳躍で2） | - | 移動と同じ跳び先の敵を攻撃 |

### シールド

- シールドルークの向いている側の縁に、横幅3マスの壁が出る（最初は敵の方向）
- 2マス以上離れた敵からの攻撃は、射線が壁を横切ると防がれる（隣からの攻撃は防げない）
- 「シールド回転」で前後左右に向きを変えられる（1キャラ分の行動を使う）

### 補給路

- 補給ナイトを選ぶ → 隣のマスを順番に押して道を決める（最後のマスを押すと1マス戻る）→「決定」
- 通った道が補給路になる。敵が補給路を踏むと、そのマスと、自陣とつながらなくなった先の部分が壊れる
- 自分の補給路の上で移動を終えると補給：**移動HP +4 / 矢・魔力 +2 / HP +1**
- 自分の補給路のマスは移動HP を使わずに通れる（高速道路）
- 数値やオンオフは `units.js` の `RULES.supply` で変えられる

## 盤面

14×14 マス。陣営は横10×縦3マス。両軍の間は 8 マス空いていて、左右にも 2 列ずつ余白がある。陣営の大きさは `units.js` の `CAMP` で変えられる。

## 陣地

- 陣取りルークが止まった場所が「陣営」（⚑）になり、周囲9マスと通ったマスが自分の陣地になる
- 両軍の初期配置のマス（チェスの初期位置の2列）は最初からその色の陣営で、乗っ取れない
- それ以外の陣地は、相手の陣取りルークに塗り替えられる
- 陣地の効果はまだない（数えて表示しているだけ）

## 友だちとネット対戦

1. `python serve.py` でサーバーを起動する（盤面の中継もこのサーバーがする）
2. 友だちが外から入れるように、トンネルで公開する（無料・登録不要）
   `cloudflared tunnel --url http://localhost:8765` → 出てきた `https://〜.trycloudflare.com` を開く
3. 「友だちと遊ぶ」→「部屋を作る」→ 出てきた合言葉かリンクを友だちに送る
4. 2人がそれぞれ自分のデッキを組んで「配置完了」を押すと試合開始（作った人が白、入った人が黒、3人目からは観戦）

同じ Wi-Fi なら `python serve.py --public` で起動して `http://<このPCのIP>:8765` でも入れる。
サーバーを止めると部屋は消える。
